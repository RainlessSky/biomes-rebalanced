This data pack's goal is to improve on vanilla biomes while sticking to a normal set of blocks.

You must load this data pack on world creation, else see a harsh border between new and old generation of some biomes. **This is incomplete, and anything is subject to change.**

**Current biomes changed**  
Almost any biome with Oak or Birch trees have the newer versions of the trees
- Birch Forest/Old Growth Birch Forest
- Oak Forest/Flower Forest
- Plains
- Desert/Badlands
- Jungles
- Warm Ocean
